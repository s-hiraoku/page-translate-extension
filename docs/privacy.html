PAGE TRANSLATE

プライバシーポリシー

最終更新日：2026年9月27日

Page Translateは、利用者が翻訳を開始したときに、表示中のページから文章を抽出して英語と日本語の翻訳を行うChrome拡張機能です。このポリシーでは、拡張機能が扱う情報、送信先、保存期間を説明します。

扱う情報と利用目的

  • ページ情報：利用者が翻訳を開始したとき、ページの文章、ページタイトル、文章の位置情報を翻訳対象の判定と表示に使います。ページのURLはサイドパネルに表示しますが、APIリクエストの本文には含めません。
  • 英作文チェックの入力：利用者が英作文チェックに入力した英文と日本語を、訳し戻し、お手本の英訳、DeepL Writeによる添削に使います。文脈として使う設定のときは、開いているページのタイトルと本文も使います。
  • APIキー：利用者が設定画面に入力したTypeSafe JevとDeepLのAPIキーを、それぞれのサービスへの認証に使います。
  • 設定：翻訳先言語、表示モード、DeepLの接続先、Jevを使うかどうか、英作文チェックの設定、データ送信への同意を拡張機能内に保存します。
  • 翻訳結果：サイドパネル表示と、利用者が選んだ場合のページ内表示に使います。

送信先と共有

翻訳を開始すると、抽出した候補文章、文章の位置情報、ページタイトル、翻訳先言語がTypeSafe JevへHTTPSで送信されます。Jevが翻訳対象に選んだ文章だけがDeepLへHTTPSで送信されます。設定でJevを使わない場合は、Jevへは送信せず、抽出した候補文章をDeepLへ送信します。英作文チェックを使うと、入力した英文と日本語、文脈として使う場合はページのタイトルと本文がDeepLへHTTPSで送信されます。APIキーは各サービスへの認証情報として各サービスに直接送信されます。

Page Translateの開発者が運営する中継サーバーはありません。開発者はページ文章、英作文チェックの入力、APIキー、翻訳結果を受信・保存せず、広告、分析、プロファイリングにも利用しません。TypeSafe JevおよびDeepLによる情報の処理は、それぞれの利用条件とプライバシーポリシーに従います。

  • TypeSafe AI プライバシーポリシー
  • DeepL プライバシーポリシー

保存と削除

  • APIキーはChromeのセッションストレージにだけ保存します。Chromeの再起動、拡張機能の無効化・再読み込み・更新で消去されます。設定画面の「保存中のAPIキーを削除」からも消去できます。
  • 翻訳設定と同意状態はこのChromeプロファイルの拡張機能ストレージに保存され、Chrome Syncには送信しません。
  • ページ文章と翻訳結果は拡張機能の永続ストレージには保存しません。サイドパネル内の結果はパネルを閉じると失われます。ページ内モードでページに適用した訳文は、原文に戻すかページを再読み込みするまで、そのページ上に表示されます。
  • 拡張機能を削除すると、拡張機能が保存した設定と同意状態も削除されます。

利用者による操作

翻訳を始める前に、文章とAPIキーがどのサービスへ送られるかを拡張機能内で表示します。利用者が「同意して翻訳を始める」を選ぶまで、ページ文章を抽出・送信しません。翻訳機能を使わず、翻訳設定を変更したり、APIキーを削除したりできます。

ポリシーの変更

データの扱いを変更するときは、このページと拡張機能内の説明を更新します。重要な変更がある場合は、変更後のデータ処理を始める前に拡張機能内で案内します。

お問い合わせ

プライバシーに関するお問い合わせは、GitHubのIssueからお送りください。Issueは公開されます。APIキー、ページ本文、個人情報を投稿しないでください。

Privacy Policy

Last updated: September 27, 2026

Page Translate is a Chrome extension that extracts text from the page you are viewing when you start a translation. It translates between English and Japanese. This policy explains what the extension handles, where information is sent, and how long it is kept.

Information and purpose

  • Page information: When you start a translation, the extension uses page text, the page title, and text-location details to select and display translations. The page URL is shown in the side panel but is not included in API request bodies.
  • Writing check input: English and Japanese text you enter in the writing check is used for back-translation, a model translation, and DeepL Write corrections. If you choose to use the open page as context, its title and main text are used too.
  • API keys: TypeSafe Jev and DeepL keys that you enter are used to authenticate requests to those services.
  • Settings: The target language, display mode, DeepL server choice, whether Jev is used, writing check options, and your data-sharing consent are stored by the extension.
  • Translations: Results are used in the side panel and, if you choose, on the page itself.

Recipients and sharing

When you start a translation, candidate page text, text-location details, the page title, and the target language are sent to TypeSafe Jev over HTTPS. Only text Jev selects for translation is sent to DeepL over HTTPS. If you turn Jev off in Settings, nothing is sent to Jev and the extracted candidate text is sent to DeepL. When you use the writing check, the English and Japanese text you enter, and the page title and main text if you use the page as context, are sent to DeepL over HTTPS. API keys are sent directly to each service for authentication.

Page Translate has no developer-operated relay server. The developer does not receive or store page text, writing check input, API keys, or translations, and does not use them for advertising, analytics, or profiling. TypeSafe Jev and DeepL process information under their respective terms and privacy policies.

  • TypeSafe AI Privacy Policy
  • DeepL Privacy Policy

Storage and deletion

  • API keys are kept only in Chrome session storage. They are cleared when Chrome restarts or when the extension is disabled, reloaded, or updated. You can also remove them from Settings.
  • Translation settings and consent state are stored in this Chrome profile and are not sent through Chrome Sync.
  • Page text and translations are not written to persistent extension storage. Side panel results disappear when the panel closes. Translations applied in page mode remain in that page until you restore the original text or reload the page.
  • Removing the extension deletes its stored settings and consent state.

Your choice

Before translation begins, the extension explains which services receive page text and API keys. It does not extract or send page text until you select “Agree and translate.” You can change settings or remove API keys without using translation.

Policy changes

If data practices change, this page and the in-extension disclosure will be updated. For material changes, the extension will explain the new processing before it begins.

Contact

For privacy questions, use GitHub Issues. Issues are public. Do not post API keys, page text, or personal information.

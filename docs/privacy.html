PAGE TRANSLATE

プライバシーポリシー

最終更新日：2026年10月5日

Page Translateは、利用者が翻訳を開始したときに、表示中のページから文章を抽出して英語と日本語の翻訳を行うChrome拡張機能です。このポリシーでは、拡張機能が扱う情報、送信先、保存期間を説明します。

扱う情報と利用目的

  • ページ情報：利用者が翻訳を開始したとき、ページの文章、ページタイトル、文章の位置情報を翻訳対象の判定と表示に使います。ページのURLはサイドパネルに表示しますが、APIリクエストの本文には含めません。
  • 選択範囲翻訳：利用者がページ上で選んだ文章を、DeepLで翻訳して選んだ場所のそばに表示するために使います。ページ全体の翻訳とは別に使え、ClaudeやJevには送りません。同じ文章をもう一度選んだときのために、翻訳結果をサイドパネルのメモリ上に一時的に（最新の50件まで）保持しますが、ディスクには保存せず、パネルを閉じると失われます。「選択したら自動で翻訳」をオンにした場合は、パネルを閉じていても、ページで選んだ文章を同じ方法でDeepLへ送って翻訳します（設定と右クリックメニューで切り替えられ、初期値はオフです）。このときの翻訳結果は、拡張機能のバックグラウンド処理のメモリ上に一時的に（最新の50件まで）保持し、ディスクには保存しません。
  • 英作文チェックの入力：利用者が英作文に入力した英文と日本語を、訳し戻し、お手本の英訳、日本語からの英訳、DeepL Writeによる添削に使います。文脈として使う設定のときは、開いているページのタイトルと本文も使います。
  • APIキー：利用者が設定画面に入力したClaude（Anthropic）、TypeSafe JevとDeepLのAPIキーを、それぞれのサービスへの認証に使います。
  • 設定：翻訳先言語、表示モード、DeepLの接続先、本文の判定に使うサービス（Claude・Jev・使わない）、英作文チェックの設定、データ送信への同意を拡張機能内に保存します。
  • 翻訳結果：サイドパネル表示と、利用者が選んだ場合のページ内表示に使います。あわせて、同じページを開き直したときに再利用するため、翻訳したページの結果を利用者の端末に一時保存します（下記「保存と削除」）。

送信先と共有

翻訳を開始すると、抽出した候補文章、文章の位置情報、ページタイトル、翻訳先言語が、本文の判定のために、設定で選んだClaude（Anthropic）またはTypeSafe JevへHTTPSで送信されます（Claudeを選んでいてそのAPIキーがない場合はJev）。判定で翻訳対象に選ばれた文章だけがDeepLへHTTPSで送信されます。設定で判定を使わない場合は、ClaudeにもJevにも送信せず、抽出した候補文章をDeepLへ送信します。選択範囲翻訳を使うと、選んだ文章がDeepLへHTTPSで送信されます。英作文チェックを使うと、入力した英文と日本語、文脈として使う場合はページのタイトルと本文がDeepLへHTTPSで送信されます。APIキーは各サービスへの認証情報として各サービスに直接送信されます。

翻訳サービスが「Chrome内蔵」（新しくインストールしたときの初期設定）の場合、翻訳はChromeに内蔵の機能で、この端末の中で行われ、文章はDeepLへ送信しません。本文の判定を「使わない」と組み合わせた場合、ページの文章はどこにも送信しません。

Page Translateの開発者が運営する中継サーバーはありません。開発者はページ文章、英作文チェックの入力、APIキー、翻訳結果を受信・保存せず、広告、分析、プロファイリングにも利用しません。Anthropic（Claude）、TypeSafe JevおよびDeepLによる情報の処理は、それぞれの利用条件とプライバシーポリシーに従います。

保存と削除

  • APIキーはChromeのセッションストレージにだけ保存します。Chromeの再起動、拡張機能の無効化・再読み込み・更新で消去されます。設定画面の「保存中のAPIキーを削除」からも消去できます。
  • 翻訳設定と同意状態はこのChromeプロファイルの拡張機能ストレージに保存され、Chrome Syncには送信しません。
  • 翻訳キャッシュ：翻訳したページの結果（ページのアドレスから#以降と広告用のパラメータを除いたもの、翻訳した文章の要約値、本文の判定結果、翻訳文）を、このChromeプロファイルの拡張機能ストレージに、設定した時間（1・3・24時間から選択、初期値は3時間）だけ保存し、同じページを開いたときに再利用します。ページの本文が変わっていた場合は翻訳し直します。保存先はこの端末の拡張機能の中だけで、外部へは送信せず、開発者も受信しません。期限を過ぎたものは自動で削除し、最大30ページまでです。設定画面の「翻訳のキャッシュ」で保存しない設定にすると保存済みの内容も削除され、「キャッシュを削除」からいつでも削除できます。
  • キャッシュ以外のページ文章と、英作文チェックの入力は、拡張機能の永続ストレージには保存しません。サイドパネル内の結果はパネルを閉じると失われます。ページ内モードでページに適用した訳文は、原文に戻すかページを再読み込みするまで、そのページ上に表示されます。
  • 拡張機能を削除すると、拡張機能が保存した設定、同意状態、翻訳キャッシュも削除されます。

利用者による操作

翻訳を始める前に、文章とAPIキーがどのサービスへ送られるかを拡張機能内で表示します。利用者が「同意して翻訳を始める」を選ぶまで、ページ文章を抽出・送信しません。翻訳機能を使わず、翻訳設定を変更したり、APIキーを削除したりできます。

ポリシーの変更

データの扱いを変更するときは、このページと拡張機能内の説明を更新します。重要な変更がある場合は、変更後のデータ処理を始める前に拡張機能内で案内します。

お問い合わせ

プライバシーに関するお問い合わせは、GitHubのIssueからお送りください。Issueは公開されます。APIキー、ページ本文、個人情報を投稿しないでください。

Privacy Policy

Last updated: October 5, 2026

Page Translate is a Chrome extension that extracts text from the page you are viewing when you start a translation. It translates between English and Japanese. This policy explains what the extension handles, where information is sent, and how long it is kept.

Information and purpose

  • Page information: When you start a translation, the extension uses page text, the page title, and text-location details to select and display translations. The page URL is shown in the side panel but is not included in API request bodies.
  • Selection translation: Text you select on a page is translated by DeepL and shown in a tooltip next to the selection. It works without translating the whole page, and nothing is sent to Claude or Jev. So that selecting the same text again costs nothing, the translation is kept briefly in the side panel's memory (the latest 50) and is never written to disk; it is lost when the panel closes. If you turn on “Translate as I select” (in Settings or the page's context menu; off by default), text you select is sent to DeepL in the same way even while the panel is closed. Those translations are kept briefly in the extension's background memory (the latest 50) and are never written to disk.
  • Writing check input: English and Japanese text you enter in the writing check is used for back-translation, a model translation, and DeepL Write corrections. If you choose to use the open page as context, its title and main text are used too.
  • API keys: Anthropic (Claude), TypeSafe Jev and DeepL keys that you enter are used to authenticate requests to those services.
  • Settings: The target language, display mode, DeepL server choice, which content judge is used (Claude, Jev or none), writing check options, and your data-sharing consent are stored by the extension.
  • Translations: Results are used in the side panel and, if you choose, on the page itself. So that a page you open again can reuse them, translated results are also kept temporarily on your device (see “Storage and deletion”).

Recipients and sharing

When you start a translation, candidate page text, text-location details, the page title, and the target language are sent over HTTPS to the content judge you chose in Settings: Claude by Anthropic, or TypeSafe Jev (Jev is used when Claude is chosen but no Claude key is registered). Only text selected for translation is sent to DeepL over HTTPS. If you choose no content judge, nothing is sent to Claude or Jev and the extracted candidate text is sent to DeepL. When you use selection translation, the text you select is sent to DeepL over HTTPS. When you use the writing check, the English and Japanese text you enter, and the page title and main text if you use the page as context, are sent to DeepL over HTTPS. API keys are sent directly to each service for authentication.

When the translation service is “Chrome built-in” (the default for new installs), translation is done by Chrome’s built-in translator on your device and no text is sent to DeepL. Combined with no content judge, page text is not sent anywhere.

Page Translate has no developer-operated relay server. The developer does not receive or store page text, writing check input, API keys, or translations, and does not use them for advertising, analytics, or profiling. Anthropic (Claude), TypeSafe Jev and DeepL process information under their respective terms and privacy policies.

  • DeepL Privacy Policy

Storage and deletion

  • API keys are kept only in Chrome session storage. They are cleared when Chrome restarts or when the extension is disabled, reloaded, or updated. You can also remove them from Settings.
  • Translation settings and consent state are stored in this Chrome profile and are not sent through Chrome Sync.
  • Translation cache: results for pages you translated (the page address without its fragment and tracking parameters, short fingerprints of the translated passages, the content judge's verdicts, and the translations) are stored in this Chrome profile's extension storage for the time you choose (1, 3 or 24 hours; 3 by default) and reused when you open the same page again. Passages that changed on the page are translated again. The cache stays inside the extension on this device: it is not sent anywhere and the developer does not receive it. Expired entries are deleted automatically, and at most 30 pages are kept. Choosing not to save in Settings (“Translation cache”) also deletes what was saved, and “Delete cache” removes it at any time.
  • Apart from the cache, page text and writing check input are not written to persistent extension storage. Side panel results disappear when the panel closes. Translations applied in page mode remain in that page until you restore the original text or reload the page.
  • Removing the extension deletes its stored settings, consent state and translation cache.

Your choice

Before translation begins, the extension explains which services receive page text and API keys. It does not extract or send page text until you select “Agree and translate.” You can change settings or remove API keys without using translation.

Policy changes

If data practices change, this page and the in-extension disclosure will be updated. For material changes, the extension will explain the new processing before it begins.

Contact

For privacy questions, use GitHub Issues. Issues are public. Do not post API keys, page text, or personal information.

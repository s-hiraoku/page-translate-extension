PAGE TRANSLATE

使い方ガイド

Page Translate は、英語と日本語のWebページを、原文の位置と結びつけて翻訳するChrome拡張機能です。ページの本文だけを選んで翻訳し、訳文を選ぶと原文のある場所へ線（コネクタ）で結びます。English guide is below.

  1. はじめに（3ステップ）
  2. ページを翻訳する
  3. 原文をクリックして訳を見る
  4. 選んだ文章だけ翻訳する
  5. 英作文をチェックする
  6. ショートカット
  7. 設定
  8. 困ったとき
  9. データの扱い

はじめに（3ステップ）

必要なものは、Chrome 116以降と、翻訳サービスのAPIキーです。キーはご自身のものを使います（開発者の共有キーはありません）。

  1. 拡張機能をインストールする。Chromeウェブストアで「Page Translate」を追加します。ツールバーのパズルのアイコンから、Page Translate を「固定」しておくと、すぐ開けます。
  2. APIキーを登録する。ツールバーの Page Translate のアイコンを押すとサイドパネルが開きます。右上の歯車から設定を開き、「APIキー」に入力して「APIキーを保存」を押します。
    • DeepL（必須）：DeepL API のページでキーを発行します。無料プラン（DeepL API Free）のキーは末尾が :fx で、接続先は自動で判定されます。
    • TypeSafe Jev（任意）：ページから翻訳する本文を選ぶサービスです。持っていなければ、設定の「翻訳する本文の判定」で「Jevを使わない」を選べば、DeepLのキーだけで使えます。
  3. 翻訳する。翻訳したいページを開き、サイドパネルの「このページを翻訳」を押します。初めてのときだけ、文章を外部サービスへ送ることの確認が出るので、内容を読んで「同意して続ける」を選びます。

APIキーはChromeのメモリ上にだけ保存されます。Chromeを終了したり、拡張機能を更新・再読み込みしたりすると消えるので、そのときはもう一度入力してください。

ページを翻訳する

「このページを翻訳」を押すと、ナビゲーションや広告などを除いた本文が翻訳されます。表示方法は2つから選べます。

表示方法できること
原文＋訳文（初期設定）ページは原文のまま、サイドパネルに訳文のカードが並びます。カードを選ぶと、ページが原文の位置までスクロールし、カードと原文がコネクタで結ばれます。コネクタは、別のカードを選ぶか、Esc を押すか、サイドパネルを閉じるまで残ります。
ページ内訳文をページの上に直接表示します。サイドパネル下の「原文に戻す」で、いつでも元に戻せます。

翻訳先は、パネル上部の「日本語へ / 英語へ」で切り替えます。翻訳できなかった文章は「この文章を翻訳」でやり直せます。

同じページを数時間以内にもう一度開くと、前回の結果を再利用するので、待たずに表示され、APIも使いません（設定で保存時間の変更・オフにできます）。訳が古いと感じたら、カードの上の「再翻訳」を押してください。

別のページへ移動したとき、またはブラウザのタブを切り替えたときは、パネルの翻訳結果は消えて最初の状態に戻ります。

原文をクリックして訳を見る（ページクリック）

ページを翻訳したあとに「ページクリック」をオンにすると、ページ上の本文をクリックするだけで、対応するカードが同じ高さに現れます。

  • まだ翻訳していない段落をクリックすると、その段落が新しいカードとして加わり、その場で翻訳されます。
  • リンクを含む本文をクリックしても、ページは移動しません。
  • 終わるには、Esc を押すか、もう一度ボタンを押すか、パネルを閉じます。

選んだ文章だけ翻訳する（選択範囲翻訳）

ページ全体を翻訳しなくても、読んでいて分からない文章だけを、その場で翻訳できます。訳は、選んだ場所のそばのツールチップに出ます（コピーもできます）。Esc か、ほかの場所のクリックで閉じます。サイドパネルを閉じたままでも使えます。

使い方やり方
1回だけ翻訳する文章を選んで、Alt+Shift+S（Macは Control+Shift+S）を押す。または、選んだ文章を右クリックして「選択範囲を翻訳」を選ぶ。
選ぶたびに自動で翻訳するページ上で右クリックして「選択したら自動で翻訳」にチェックを入れる。または、設定の「選択したら自動で翻訳」を「オン」にする。初期値はオフです。
サイドパネルのボタンで、オンにするパネルの「選択範囲翻訳」ボタンを押すと、パネルを開いているあいだだけオンになります（パネルを閉じるとオフ）。
  • 翻訳にはDeepLだけを使います（Jevは使いません）。
  • 翻訳先は、パネルの「日本語へ / 英語へ」に従います。すでに翻訳先の言語の文章は、翻訳しません。
  • 1回に翻訳できるのは5,000文字までです。
  • iframeの中、入力欄の中、PDFビューアなどでは使えません。
  • 初めて使うときは、データ送信への同意が必要です。パネルを閉じているときは、ツールチップの案内に従って、パネルを開いて同意してください。

英作文をチェックする

サイドパネルの「英作文」タブには、2つの使い方があります。

英文をチェック

自分で書いた英文を入れて「英文をチェック」を押すと、次を表示します。

  • 伝わる意味：英文を日本語に訳し戻した結果。相手にこう伝わる、という確認になります。「言いたいこと」を日本語で書いておくと、並べて比べられます。
  • お手本の英訳：「言いたいこと」の英訳と、自分の英文との違い。
  • DeepL Writeの添削：綴りや文法を整えた英文と、自分の英文との違い（DeepLの有料プランのキーのみ）。

日本語から英訳

言いたいことを日本語で書くと、英語にします。英訳（コピーできます）と、その訳し戻しを表示します。有料プランのキーなら、DeepL Writeで選んだ文体（ビジネス、カジュアルなど）に整えた英文も出ます。

設定

項目内容
翻訳する本文の判定「Jevを使う」（初期値）は、TypeSafe Jevが翻訳する本文を選びます。「Jevを使わない」は、ページ側のルールで除いた残りをすべてDeepLで翻訳します（Jevのキーは不要）。
DeepLの接続先「自動」のとき、キーの末尾が :fx なら無料用、それ以外は有料用に接続します。合わなければ手動で選べます。
選択したら自動で翻訳サイドパネルを閉じていても、文章を選ぶたびに自動で翻訳します（初期値はオフ）。
翻訳のキャッシュ翻訳したページの結果を、この端末の拡張機能の中だけに、1・3・24時間（初期値3時間）保存します。「キャッシュを削除」で消せます。
表示テーマサイドパネルの配色を、システム・ライト・ダークから選びます。
英作文の設定英語の種類（米国・英国）、DeepL Writeの文体、「日本語を英訳するとき、開いているページを文脈として使う」（初期値はオフ）。

困ったとき

「このページと接続できませんでした」と表示される

拡張機能をインストール・更新する前から開いていたページでは、まだ拡張機能が読み込まれていません。ページを再読み込みしてから、もう一度試してください。chrome:// のページやChromeウェブストアなどでは使えません。

翻訳を押しても何も起きない・「APIキーが未設定」と出る

設定でDeepLのAPIキーを登録したか確認してください。キーはChromeを終了すると消えるので、起動し直したあとは再入力が必要です。「Jevを使う」設定のときは、TypeSafe Jevのキーも必要です（持っていなければ「Jevを使わない」を選びます）。

日本語のページ、または一部の文章が翻訳されない

翻訳先がすでに日本語のとき、日本語の文章は翻訳しません。また、本文以外（ナビゲーション、広告、メタ情報など）と、翻訳しなくてよいと判定された文章は、一覧に出ません。パネルの「表示していません」の件数で、除いた数が分かります。除かれた文章も、ページクリックで、クリックすれば翻訳できます。

ショートカットが効かない

設定の「ショートカット」に「未設定」と出ていたら、ほかの拡張機能や、Chrome自身が同じキーを使っています。chrome://extensions/shortcuts で、別のキーを割り当ててください。

選択範囲翻訳のツールチップが出ない

iframeの中、入力欄の中、PDFビューアでは使えません。また、2文字未満や、数字・記号だけの選択は翻訳しません。初めて使うときは、データ送信への同意が必要です。パネルを開いて、一度どれかの翻訳を試し、同意してください。

コネクタ（原文と結ぶ線）が出ない・ずれる

コネクタは、サイドパネルのカードを選んだときに出ます。出ないときやずれたときは、もう一度カードを選んでください。ページの内容が変わっていて原文が見つからないときは、もう一度ページを翻訳してください。

訳が古い・変わらない

キャッシュが使われています。カードの上の「再翻訳」を押すと、キャッシュを使わずに翻訳し直します。設定でキャッシュをオフにすることもできます。

ほかの問題・要望

GitHubのIssuesで受け付けています。

データの扱い

  • 翻訳を始めると、ページから取り出した文章とページタイトルがTypeSafe Jevへ、翻訳する文章がDeepLへ送られます。「Jevを使わない」設定のときは、DeepLだけへ送ります。
  • 選択範囲翻訳と英作文は、DeepLだけへ送ります。
  • 開発者が運営するサーバーはありません。ページの文章、APIキー、翻訳結果は、開発者へは届きません。
  • 個人情報や機密情報を含む文章を翻訳するときは、ご利用のAPIプランの条件を確認してください。

くわしくはプライバシーポリシーをご覧ください。

PAGE TRANSLATE

User guide

Page Translate is a Chrome extension that translates English and Japanese web pages and ties every translation to its place in the original text. It picks out the body text of a page, translates it, and draws a line (a connector) from the translation you select to its source.

Getting started (3 steps)

You need Chrome 116 or later and an API key for the translation service. You use your own key; there is no shared key from the developer.

  1. Install the extension. Add “Page Translate” from the Chrome Web Store, and pin it from the puzzle-piece menu so it is one click away.
  2. Register your API key. Click the Page Translate icon to open the side panel, open Settings with the gear at the top right, type the key under “API key” and press “Save API keys”.
    • DeepL (required): get a key from DeepL API. Free-plan keys end in :fx; the endpoint is detected automatically.
    • TypeSafe Jev (optional): the service that chooses which text on the page to translate. If you do not have a key, choose “Don't use Jev” in Settings and the DeepL key alone is enough.
  3. Translate. Open a page and press “Translate this page” in the side panel. The first time, a screen explains that text is sent to external services; read it and choose to continue.

API keys are kept only in Chrome's memory. They are cleared when Chrome quits or the extension is updated or reloaded; enter them again then.

Translate a page

The body text (without navigation, ads and the like) is translated. Choose how it is shown:

  • Source + translation (default): the page stays as it is and translation cards appear in the side panel. Select a card and the page scrolls to the source, joined to the card by a connector that stays until you select another card, press Esc or close the panel.
  • In page: translations are shown directly in the page; “Restore original” at the bottom of the panel undoes it.

Switch the target with “To Japanese / To English” at the top of the panel. Opening the same page again within a few hours reuses the earlier result; press “Retranslate” above the cards to translate from scratch. When you go to another page or switch browser tabs, the panel's results are cleared and it returns to its start screen.

Click the page to see its translation (page click)

After translating, turn on “Page click”. Clicking body text on the page shows the matching card at the same height. Clicking text that was not translated adds it as a new card and translates it. Links inside body text do not navigate while this is on. Press Esc, press the button again or close the panel to stop.

Translate only what you select (selection translation)

Translate just the passage you are stuck on, in a tooltip next to the selection (copyable; Esc or a click elsewhere closes it). It works with the side panel closed.

  • Once: select text and press Alt+Shift+S (Mac: Control+Shift+S), or right-click the selection and choose “選択範囲を翻訳” (Translate selection).
  • Every time you select: tick “選択したら自動で翻訳” (Translate as I select) in the page's right-click menu, or set it to On in Settings. It is off by default.
  • With the panel: the “Selection translation” button in the panel turns the mode on only while the panel is open.

Only DeepL is used. Text already in the target language is not translated, and up to 5,000 characters can be translated at a time. It does not work inside iframes, form fields or the PDF viewer. The first time, you must agree to the data use; if the panel is closed, follow the hint in the tooltip and agree in the panel.

Check your English writing

The “Writing” tab has two tools. “Check my English” shows what your English conveys (a back-translation), a model translation of what you meant compared with your sentence, and — with a paid DeepL key — a DeepL Write correction. “Japanese to English” turns what you write in Japanese into English, with its back-translation and, with a paid key, a version in the style you choose.

Troubleshooting

“Could not connect to this page”

Pages that were open before the extension was installed or updated need a reload. Extension pages such as chrome:// and the Chrome Web Store cannot be translated.

Nothing happens, or “API key not set”

Check that the DeepL key is registered in Settings. Keys are cleared when Chrome quits. With “Use Jev” on, a TypeSafe Jev key is needed too; otherwise choose “Don't use Jev”.

A shortcut does nothing

If Settings shows “Not set”, another extension or Chrome itself uses that key. Assign another at chrome://extensions/shortcuts.

The selection tooltip does not appear

It is not available in iframes, form fields or the PDF viewer, and selections under two characters or made only of digits and symbols are skipped. The first use needs your agreement to the data use.

The translation looks out of date

A cached result is used. Press “Retranslate” above the cards, or turn the cache off in Settings.

Anything else

Please open an issue on GitHub.

Your data

When you translate a page, the text extracted from it and the page title go to TypeSafe Jev, and the text to translate goes to DeepL (only DeepL with “Don't use Jev”). Selection translation and the writing tools use DeepL only. There is no server run by the developer, and page text, API keys and translations never reach the developer. See the privacy policy.

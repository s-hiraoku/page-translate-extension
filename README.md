# Page Translate

英語と日本語のページを、原文の位置と結びつけて翻訳するChrome拡張機能です。TypeSafe Jevがページから翻訳する文章を選び、DeepLが選ばれた文章を翻訳します。

## 翻訳の見せ方

- **原文＋サイドパネル翻訳**：ページは原文のまま。サイドパネルの項目から原文の位置へ移動し、コネクタで対応箇所を示します。コネクタはページやパネルをスクロールしても追従し、別の項目を選ぶ・Esc キーを押す・サイドパネルを閉じるまで表示されます。本文外（ナビゲーション、広告、メタ情報など）や翻訳対象外の文章は一覧に表示しません。
- **ページ内翻訳**：翻訳文をページ上に表示します。いつでも原文へ戻せます。

翻訳後に「ページクリック」をオンにすると、ページ上の本文をクリックするだけで対応する訳文のカードを同じ高さに表示し、コネクタで結びます。翻訳対象になっていない箇所をクリックすると、その段落を新しいカードとして追加し、DeepLで翻訳します。文字を選択すると、選択した部分だけを翻訳します。リンクを含む本文をクリックしてもページは移動しません。Escキー・ボタンの再押下・パネルを閉じる操作で終了します。

設定画面の「表示テーマ」で、サイドパネルの配色をシステム・ライト・ダークから選べます。

## 使い方

Chromeウェブストアからインストール後、歯車アイコンからTypeSafe JevとDeepLのAPIキーを登録します。翻訳を始める前に、ページ文章が各サービスへ送信されることを確認する画面が表示されます。初回は「同意して翻訳を始める」を選んでください。

APIキーは拡張機能のメモリ上にだけ保存され、Chromeの終了、拡張機能の再読み込み・更新・無効化で消えます。次回の起動時には再入力してください。設定画面からいつでも削除できます。APIキーはこの拡張機能を使う人自身のものを登録します。開発者の共有キーや中継サーバーは使いません。

## データの送信

翻訳を開始すると、ページから抽出した候補文章とページタイトルがTypeSafe Jevへ送信されます。Jevが翻訳対象に選んだ文章だけをDeepLへ送ります。APIキーは各サービスの認証に使います。Page Translateの開発者はページ文章、APIキー、翻訳結果を受信・保存しません。

## 開発と提出用パッケージ

- Node.js 20.19以上、または22.12以上
- Chrome 114以上

```sh
npm install
npm run build
npm run zip
```

`npm run zip` は `.output/page-translate-v<version>-chrome.zip` を作成します。ZIPを開いたとき、`manifest.json` が直下にある構成です。開発中は `dist` を `chrome://extensions` の「パッケージ化されていない拡張機能を読み込む」から読み込みます。

`main` への push では、GitHub Actions が同じ `npm run zip` を実行し、できた ZIP をアーティファクトとして残します。アーティファクト名は ZIP のファイル名と同じです（例: `page-translate-v1.0.0-chrome.zip`）。ダウンロードしたファイルが提出用 ZIP そのものです。

公開するときは、`src/manifest.ts` の `version` と `package.json` の `version` を同じ値にしたうえで、`v1.0.0` のように `v` と version を続けたタグを push します。GitHub Actions が同じ `npm run zip` を実行し、できた ZIP をそのタグの GitHub Release に添付します。

プライバシーポリシーは [`docs/privacy.html`](docs/privacy.html) を GitHub Pages で公開します。公開 URL は https://s-hiraoku.github.io/page-translate-extension/privacy.html です。

## 権限

- `sidePanel`：翻訳結果と設定をChromeサイドパネルに表示します。
- `storage`：表示設定と、初回データ送信への同意を保存します。APIキーはChromeのセッションストレージにだけ置きます。
- すべてのWebページでのコンテンツスクリプト：ユーザーが翻訳を開始したとき、表示中の文章を抽出し、選択された表示方法を適用します。
- TypeSafe Jev / DeepL の接続先：翻訳対象の分類と翻訳を行います。

## プライバシー

詳細は [`docs/privacy.html`](docs/privacy.html) を参照してください。提出時は上の公開 URL を確認し、Chrome Web Store のプライバシーポリシー欄に登録します。

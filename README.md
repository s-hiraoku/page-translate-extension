# Page Translate

英語と日本語のWebページを、原文の位置と結びつけて翻訳するChrome拡張機能です。ページの本文だけを選んで翻訳し、訳文を選ぶと、原文のある場所へ線（コネクタ）で結びます。パソコン版のChrome 138以降なら、Chromeに内蔵の翻訳を使うので、**APIキーなしですぐに使えます**。

**📖 [使い方ガイド](https://s-hiraoku.github.io/page-translate-extension/)**（画面の説明、困ったときの対処つき） ・ [English guide](https://s-hiraoku.github.io/page-translate-extension/#en) ・ [プライバシーポリシー](https://s-hiraoku.github.io/page-translate-extension/privacy.html)

## できること

- **ページ翻訳**：ナビゲーションや広告を除いた本文を翻訳します。「原文＋訳文」（ページは原文のまま、サイドパネルに訳文のカード。選ぶと原文へ移動）と、「ページ内」（訳文をページに直接表示。いつでも原文に戻せます）から選べます。
- **ページクリック**：翻訳後にオンにすると、ページの本文をクリックするだけで、対応する訳文のカードが現れます。翻訳していない段落も、クリックで追加して翻訳できます。
- **選択範囲翻訳**：ページ全体を翻訳せずに、選んだ文章だけを、その場のツールチップに翻訳します。サイドパネルを閉じたままでも使えます（ショートカット、右クリック、「選択したら自動で翻訳」）。
- **英作文**：自分の英文が相手にどう伝わるかを、訳し戻しで確かめます。日本語から英訳もできます。
- **翻訳のキャッシュ**：同じページを数時間以内に開き直すと、前回の結果を再利用します。
- **翻訳サービスを選べる**：初期設定は「Chrome内蔵」で、APIキーなしに、この端末の中で翻訳します（パソコン版のChrome 138以降。それより前の版ではDeepLを使います）。DeepLのAPIキーを登録すれば、設定でDeepLに切り替えられます。

## はじめかた（3ステップ）

1. **インストール**：Chromeウェブストアで「Page Translate」を追加します。
2. **翻訳**：ページを開き、ツールバーのアイコンでサイドパネルを開いて「このページを翻訳」を押します。初回だけ、Chromeの翻訳モデルのダウンロードがあります。
3. **必要なら APIキーを登録**：DeepLで翻訳したいときや英作文を使うときは、右上の歯車から設定を開いて、DeepLのAPIキーを登録します（無料プランのキーで使えます）。TypeSafe Jevのキーを登録すると、Jevがページから翻訳する本文を選びます。

Chrome内蔵の翻訳には、パソコン版のChrome 138以降が必要です（拡張機能そのものはChrome 116以降で動き、そのときはDeepLで翻訳します）。APIキーはご自身のものを使います（開発者の共有キーや中継サーバーはありません）。キーはChromeのメモリ上にだけ保存され、Chromeを終了したり拡張機能を更新・再読み込みしたりすると消えるので、そのときは再入力してください。DeepLやJevへ文章を送るときは、初回だけ送信の確認が出ます。

## ショートカット

| 操作 | Windows / Linux | Mac |
|---|---|---|
| このページを翻訳（サイドパネルが閉じていれば開く） | Alt+Shift+Y | Control+Shift+Y |
| ページクリックのオン・オフ（未翻訳なら翻訳してからオン） | Alt+Shift+K | Control+Shift+K |
| 選んだ文章を翻訳（サイドパネルを閉じたままでも、ツールチップで表示） | Alt+Shift+S | Control+Shift+S |

キーは `chrome://extensions/shortcuts`（設定画面の「ショートカットを変更」）で変更できます。ほかの拡張機能と同じキーは割り当てられず、設定画面に「未設定」と表示されます。

## 困ったとき

- **「このページと接続できませんでした」**：拡張機能を入れる前から開いていたページは、再読み込みしてください。`chrome://` のページとChromeウェブストアでは使えません。
- **翻訳できない・「APIキーが未設定」**：設定でDeepLのキーを登録したか確認してください。キーはChromeを終了すると消えます。
- **更新したあと、選択範囲翻訳（自動）が動かない**：更新前から開いていたページを再読み込みし、DeepLのキーを登録し直してください（更新でキーが消えます）。パネルの「選択範囲翻訳」ボタンは、パネルを閉じるとオフになります。パネルを閉じたまま使うには、設定か右クリックの「選択したら自動で翻訳」をオンにします。
- **訳が古い**：カードの上の「再翻訳」で、キャッシュを使わずに翻訳し直せます。
- **選択範囲翻訳が出ない**：iframeの中、入力欄の中、PDFビューアでは使えません。DeepLで翻訳する場合、初めては、データ送信への同意が必要です。

そのほかは[使い方ガイド](https://s-hiraoku.github.io/page-translate-extension/#trouble)を、不具合や要望は[Issues](https://github.com/s-hiraoku/page-translate-extension/issues)をご覧ください。

## データの送信

翻訳を開始すると、ページから抽出した候補文章とページタイトルがTypeSafe Jevへ送信されます。Jevが翻訳対象に選んだ文章だけをDeepLへ送ります。設定で「Jevを使わない」を選んだ場合は、Jevへは送信せず、抽出した候補文章をDeepLへ送ります。翻訳に使うサービスが「Chrome内蔵」の場合は、翻訳をこの端末の中で行い、DeepLへは送りません（選択範囲翻訳も同じです）。DeepLの場合、選択範囲翻訳は選んだ文章をDeepLだけへ送ります。英作文チェックでは、入力した英文と日本語、文脈として使う場合はページのタイトルと本文をDeepLへ送ります。APIキーは各サービスの認証に使います。Page Translateの開発者はページ文章、APIキー、翻訳結果を受信・保存しません。

詳細は[プライバシーポリシー](docs/privacy.html)を参照してください。

## 権限

- `contextMenus`：ページ上の右クリックメニューに「選択範囲を翻訳」と「選択したら自動で翻訳」を表示します。
- `sidePanel`：翻訳結果と設定をChromeサイドパネルに表示します。
- `storage`：表示設定と、初回データ送信への同意を保存します。翻訳したページの結果も、同じページを開き直したときに再利用するため一定時間（初期値3時間）保存します。APIキーはChromeのセッションストレージにだけ置きます。
- すべてのWebページでのコンテンツスクリプト：ユーザーが翻訳を開始したとき、表示中の文章を抽出し、選択された表示方法を適用します。
- TypeSafe Jev / DeepL の接続先：翻訳対象の分類と翻訳を行います。

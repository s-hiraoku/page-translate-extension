# Page Translate

英語と日本語のページを、原文の位置と結びつけて翻訳するChrome拡張機能です。TypeSafe Jevがページから翻訳する文章を選び、DeepLが選ばれた文章を翻訳します。

## 翻訳の見せ方

- **原文＋サイドパネル翻訳**：ページは原文のまま。サイドパネルの項目から原文の位置へ移動し、コネクタで対応箇所を示します。コネクタはページやパネルをスクロールしても追従し、別の項目を選ぶ・Esc キーを押す・サイドパネルを閉じるまで表示されます。本文外（ナビゲーション、広告、メタ情報など）や翻訳対象外の文章は一覧に表示しません。
- **ページ内翻訳**：翻訳文をページ上に表示します。いつでも原文へ戻せます。

翻訳後に「ページクリック」をオンにすると、ページ上の本文をクリックするだけで対応する訳文のカードを同じ高さに表示し、コネクタで結びます。翻訳対象になっていない箇所をクリックすると、その段落を新しいカードとして追加し、DeepLで翻訳します。文字を選択すると、選択した部分だけを翻訳します。リンクを含む本文をクリックしてもページは移動しません。Escキー・ボタンの再押下・パネルを閉じる操作で終了します。

設定画面の「表示テーマ」で、サイドパネルの配色をシステム・ライト・ダークから選べます。

## 使い方

Chromeウェブストアからインストール後、歯車アイコンからTypeSafe JevとDeepLのAPIキーを登録します。翻訳を始める前に、ページ文章が各サービスへ送信されることを確認する画面が表示されます。初回は「同意して翻訳を始める」を選んでください。

キーボードショートカットでも操作できます。

| 操作 | Windows / Linux | Mac |
|---|---|---|
| このページを翻訳（サイドパネルが閉じていれば開く） | Alt+Shift+Y | Control+Shift+Y |
| ページクリックのオン・オフ（未翻訳なら翻訳してからオン） | Alt+Shift+K | Control+Shift+K |

Y は「訳」、K は「クリック」から取っています。キーは `chrome://extensions/shortcuts`（設定画面の「ショートカットを変更」）で変更できます。ほかの拡張機能がすでに同じキーを使っている場合は割り当てられず、設定画面に「未設定」と表示されます。

「英作文」タブには2つの使い方があります。

「英文をチェック」では、自分で書いた英文を確認できます。「英文をチェック」を押すと、次の3つを表示します。

- 伝わる意味：英文を日本語に訳し戻した結果。「言いたいこと」を書いた場合は並べて表示します
- お手本の英訳：「言いたいこと（日本語）」を書いた場合の、DeepLによる英訳と自分の英文との差分
- DeepL Writeの添削：綴りや文法を整えた英文と自分の英文との差分（有料プランのキーのみ）

「日本語から英訳」では、言いたいことを日本語で書くと英語にします。英訳（コピーできます）、英訳を日本語に戻した訳し戻し、DeepL Writeで選んだ文体に整えた英文（有料プランのキーのみ）を表示します。

DeepLの接続先は、設定画面の「接続先」が「自動」のとき、キーの末尾で判定します。末尾が `:fx` のキーは無料プラン用として `api-free.deepl.com` を、それ以外は `api.deepl.com` を使います。判定が合わない場合は手動で選べます。

「日本語を英訳するとき、開いているページを文脈として使う」をオンにすると、日本語を英訳するときに開いているページのタイトルと本文を参考情報としてDeepLに渡し、ページの話題に合った英訳になりやすくします。初期設定はオフです。訳し戻しには文脈を使わず、英文そのものの意味を表示します。

設定画面の「翻訳する本文の判定」で、Jevを使うかどうかを選べます。「Jevを使わない」にすると、ページ側のルールで除いた残りをすべてDeepLで翻訳します。このときJevのAPIキーは不要です。同じページで両方を試すと、Jevが翻訳対象から外した箇所を確認できます。

翻訳したページの結果は、この端末の拡張機能の中だけに、設定した時間（1・3・24時間、初期値3時間）保存され、同じページを開き直したときに再利用されます。外部へは送信しません。ページの本文が変わっていた部分は翻訳し直します。設定画面の「翻訳のキャッシュ」で保存をやめたり、「キャッシュを削除」で消したりできます。翻訳の結果が古いと感じたときは、カードの上の「再翻訳」でキャッシュを使わずに翻訳し直せます。

APIキーは拡張機能のメモリ上にだけ保存され、Chromeの終了、拡張機能の再読み込み・更新・無効化で消えます。次回の起動時には再入力してください。設定画面からいつでも削除できます。APIキーはこの拡張機能を使う人自身のものを登録します。開発者の共有キーや中継サーバーは使いません。

## データの送信

翻訳を開始すると、ページから抽出した候補文章とページタイトルがTypeSafe Jevへ送信されます。Jevが翻訳対象に選んだ文章だけをDeepLへ送ります。設定で「Jevを使わない」を選んだ場合は、Jevへは送信せず、抽出した候補文章をDeepLへ送ります。英作文チェックでは、入力した英文と日本語、文脈として使う場合はページのタイトルと本文をDeepLへ送ります。APIキーは各サービスの認証に使います。Page Translateの開発者はページ文章、APIキー、翻訳結果を受信・保存しません。

## 開発と提出用パッケージ

- Node.js 20.19以上、または22.12以上
- Chrome 116以上

```sh
npm install
npm run build
npm run zip
```

`npm run zip` は `.output/page-translate-v<version>-chrome.zip` を作成します。ZIPを開いたとき、`manifest.json` が直下にある構成です。開発中は `dist` を `chrome://extensions` の「パッケージ化されていない拡張機能を読み込む」から読み込みます。

`main` への push では、GitHub Actions が同じ `npm run zip` を実行し、できた ZIP をアーティファクトとして残します。アーティファクト名は ZIP のファイル名と同じです（例: `page-translate-v1.5.0-chrome.zip`）。ダウンロードしたファイルが提出用 ZIP そのものです。

公開するときは、`src/manifest.ts` の `version` と `package.json` の `version` を同じ新しい値にして `main` にマージします。マージすると GitHub Actions の「Release」ワークフローが自動で動き、`npm test` と `npm run zip` を実行して、`v1.5.0` のようなタグと GitHub Release を作り、ZIP を添付します。すでにリリース済みの version のままなら何もしません。

ほかに次の方法でもリリースできます。

- GitHub の Actions タブで「Release」ワークフローを手動実行する（`ref` は通常 `main`）。同じタグがすでにある場合は失敗します。
- `v1.5.0` のように `v` と version を続けたタグを push する。

### テスト

```sh
npm test            # ユニットテスト（Vitest）
npm run test:e2e    # ビルドしてから、実際の拡張機能をChromiumで動かすE2Eテスト（Playwright）
```

初回だけ `npx playwright install chromium` でテスト用のChromiumを入れてください。

- `tests/unit`：本文判定のルール（`src/sidepanel/rules.ts`）、英作文の差分、ページ種別の判定、DeepLのプラン判定
- `tests/e2e/content-script.spec.ts`：`dist` を拡張機能として読み込み、`tests/e2e/fixtures` のページで本文抽出、ページ内翻訳、コネクタ、ページクリックモードを確かめます
- `tests/e2e/side-panel.spec.ts`：ビルドしたサイドパネルを `chrome.*` のモック（`tests/e2e/support/chrome-mock.ts`）付きで開き、カード表示、Jevのオン・オフ、同意、英作文チェックを確かめます

不具合を直したときは、再発を防ぐテストを一緒に追加してください。サイトで問題が出たときは、該当部分を最小限のHTMLにして `tests/e2e/fixtures` に置くと再現できます。`E2E_DIST=<別ビルドのdist> npx playwright test` で、過去のリリースに対して同じテストを実行できます。

pull request と `main` への push では、GitHub Actions が型チェック、ユニットテスト、ビルド、E2Eテストを実行します。

プライバシーポリシーは [`docs/privacy.html`](docs/privacy.html) を GitHub Pages で公開します。公開 URL は https://s-hiraoku.github.io/page-translate-extension/privacy.html です。

## 権限

- `sidePanel`：翻訳結果と設定をChromeサイドパネルに表示します。
- `storage`：表示設定と、初回データ送信への同意を保存します。翻訳したページの結果も、同じページを開き直したときに再利用するため一定時間（初期値3時間）保存します。APIキーはChromeのセッションストレージにだけ置きます。
- すべてのWebページでのコンテンツスクリプト：ユーザーが翻訳を開始したとき、表示中の文章を抽出し、選択された表示方法を適用します。
- TypeSafe Jev / DeepL の接続先：翻訳対象の分類と翻訳を行います。
